## What this session achieved

Reduced browser test harness initialisation from **~1.5 seconds to ~36 ms** on repeat runs by replacing ephemeral threading-based infrastructure with persistent subprocess-managed servers and module-level browser singletons.

Key introduction: `sg_send_qa/local_servers/` — a new package with `Server__Base__Local` hierarchy, `QA__Local_Servers` config coordinator, and `QA__Local_Browser` Chromium path cache.

## Key Findings at a Glance

### Performance Numbers (from commit history)

| Metric | Before | After |
|--------|--------|-------|
| Full harness setup (1st run) | ~1.5 s | ~1.35 s |
| Full harness setup (2nd+ run) | ~1.5 s | **~36 ms** |
| API server start | ~230 ms | ~15 ms (reuse) |
| Browser connection | ~370 ms | ~0 ms (singleton) |
| `sync_playwright().start()` | ~374 ms/run | ~0 ms (cached path) |
| `browser_via_cdp` | ~395 ms/run | ~0 ms (singleton) |

### P0 Risks (from QA brief)
1. `Safe_Str__Python__FastAPI_Handler` imported from `tests/` into production schema — **breaks package install**
2. Stale PID reuse after OS restart silently prevents server start
3. `server__configured_ok()` defaults to `False` — silent failure if subclass forgets to override
4. Lost static config constants from commit `28e89cb` refactor
5. No timeout on `wait_for__port__open` / `wait_for__port__closed` — CI hang risk

### New Architecture (from Architect brief)
```
QA__Local_Servers
    ├── Server__API__Send_SGraph_AI   (port 50001, subprocess FastAPI)
    └── Server__Http__Send_SGraph_AI  (port 50002, subprocess static)

QA__Local_Browser
    └── .local-servers/browser-config.json  (Chromium path cache)

QA_Browser (module-level singletons)
    ├── _qa_browser           (headless=True)
    └── _qa_browser__headless (headless=False)
```

### Naming Fix Needed
All `Page__Send_SGraph_Ai__*` classes should be renamed `Page__Send_SGraph_AI__*` (capitalise both letters of "AI") — noted by Dinis in `@dev` tag.
